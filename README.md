# 🎮 Simon Says Game

A fun and interactive **Simon Says Memory Game** built using **HTML, CSS, and JavaScript**.

The game challenges players to remember and repeat an increasingly long sequence of colors. With every successful round, the difficulty increases as a new color is added to the sequence.

---

* 🎮 Interactive memory-based gameplay
* 🎨 Four colorful game buttons
* 🔢 Increasing difficulty with every level
* 🧠 Tests memory and concentration
* ✨ Button animations and visual feedback
* 🔊 Interactive gameplay experience
* ❌ Game-over screen when the sequence is incorrect

## 🎯 How to Play

1. Open the game in your browser.
2. Press any key or the **Start** button to begin.
3. The game will highlight a color.
4. Remember the highlighted sequence.
5. Click the buttons in the same order.
6. If your sequence is correct, you move to the next level.
7. Each new level adds another color to the sequence.
8. If you click the wrong color, the game ends.
9. Restart the game and try to beat your previous level.

---

## 🧠 Game Logic

The game works using two sequences:

* **Game Sequence** – The sequence generated by the game.
* **User Sequence** – The sequence entered by the player.

At every level:

```text
Game generates a new color
        ↓
Color is added to the sequence
        ↓
Sequence is shown to the player
        ↓
Player repeats the sequence
        ↓
Correct → Next Level
Wrong → Game Over
```

## 📈 Difficulty

The game becomes progressively harder because the sequence gets longer after every successful level.

For example:

```text
Level 1 → 🔴

Level 2 → 🔴 🟢

Level 3 → 🔴 🟢 🔵

Level 4 → 🔴 🟢 🔵 🟡

Level 5 → 🔴 🟢 🔵 🟡 🟢
```

The player must remember the complete sequence to continue.
